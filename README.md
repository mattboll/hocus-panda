# Hocuspanda

A Wayland desktop for developers who work with AI agents: see at a glance
what your agents are doing; everything else beautiful, fluid and out of
the way.

This is the v2, restarted from the vision and the design. Start with
[docs/vision.md](docs/vision.md) and [the bar's spec](docs/design/bar.md).
The first build is kept under the tag `v0-first-build`.
